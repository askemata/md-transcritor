Transcrição

Os arquivos e chaves de API ficam só no seu navegador (localStorage). Nada passa por servidor próprio — cada transcrição chama diretamente a API do provedor escolhido.

Configurações

Escolha o provedor de IA e informe sua própria chave de API. Você pode configurar mais de um.

Google Gemini tem nível gratuito

Único provedor que lê PDF, vídeo do YouTube e páginas da web de forma nativa (sem bloqueios de CORS). Recomendado como padrão. Chave grátis em aistudio.google.com.

Anthropic Claude

Boa leitura de PDF (inclusive digitalizados). Não busca vídeos do YouTube nem páginas da web por conta própria — use o Gemini para essas duas abas.

Endpoint personalizado

Qualquer API compatível com o formato de chat da OpenAI (ex.: OpenAI, Groq, OpenRouter). Precisa aceitar imagens (visão) para transcrever PDF.

Salvo só neste navegador.
